I started with **Scratch**. Snapping blocks together turned into wanting to know what was happening underneath, and that turned into real code. I never really stopped.

Most of my projects still start the same way:

> *"Could I build this myself?"*

Sometimes the answer is yes. Sometimes the answer is several hundred commits later.

## 🚀 What I'm building

### 🧠 Prefrontal

**A lightweight, self-hostable AI frontend that works with the models you want to use.**

| | |
|---|---|
| 🔌 **Multi-provider** | Switch between AI providers without switching apps |
| 🏠 **Local models** | Run your own models alongside hosted ones |
| ⚡ **Lightweight** | Fast to load, easy to host, no bloat |
| 🎨 **Modern UI** | Clean interface that stays out of your way |
| 🔓 **Open source** | Built in the open, contributions welcome |
